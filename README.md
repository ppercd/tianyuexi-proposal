# 方案网站修改与复用说明

## 直接预览

双击 `index.html`。页面不依赖服务器，也不需要安装软件。

## 制作下一个项目

1. 复制整个文件夹并改名。
2. 把项目图片放进 `assets`，建议使用 WebP 或压缩后的 JPG。
3. 只编辑 `project-data.js`：项目名、日期、面积、理念、空间与图片页码都集中在这里。
4. 想修改字体、颜色和尺寸时，编辑 `styles.css`。

## 图片与空间数据

每个空间都由以下字段组成：

```js
{
  id: "living",
  name: "客厅",
  en: "SITTING ROOM",
  summary: "空间设计说明",
  pages: [17, 18, 19, 20]
}
```

当前版本为了最大程度保留原提案排版，使用了 PDF 整页图片。正式上线时可以进一步裁出单张效果图，以获得更自由的网页排版和更清晰的手机体验。

## 发布建议

可直接部署到 Cloudflare Pages、Vercel、腾讯云静态网站或阿里云 OSS。涉及客户隐私时，请增加访问密码，并关闭搜索引擎收录。
